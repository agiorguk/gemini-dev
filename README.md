# gemini-dev

This repository hosts the preview of the GEMINI documentation at `https://agiorguk.github.io/gemini-dev/`. GitHub Pages allows only one site per repository, so the preview needs a repository of its own.

Each push to the `dev` branch of agiorguk/gemini runs a workflow there that converted the AsciiDoc pages to HTML and pushed the result to this repository's `gh-pages` branch. Nothing here should be edited.

## Where to go now

| What | Where |
| --- | --- |
| Live GEMINI site, built from `main` | https://agiorguk.github.io/gemini/ |
| Preview of upcoming changes, built from `[dev](https://github.com/agiorguk/gemini/tree/dev)` | [https://agiorguk.github.io/gemini/dev/](https://agiorguk.github.io/gemini-dev/) |
| Source, issues and pull requests | https://github.com/agiorguk/gemini |

Please raise issues and pull requests on [agiorguk/gemini](https://github.com/agiorguk/gemini), not here.
